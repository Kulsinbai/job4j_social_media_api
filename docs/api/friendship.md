# API дружбы

## Получить список друзей

**Метод и путь:** GET /api/friendships

**Кто выполняет запрос:** авторизованный пользователь.

**Передаваемые данные:** тело запроса отсутствует.
Текущий пользователь определяется по данным авторизации.

**Результат:** список друзей текущего пользователя.

### Успешный ответ

Код ответа: 200 OK.

Пример для пользователя 1, у которого есть друзья 2 и 3:

```json
[
  {
    "userId": 2
  },
  {
    "userId": 3
  }
]
```

Если друзей нет, возвращается пустой массив:

```json
[]
```

Запрос не изменяет заявки, дружбу и подписки.
Повторный запрос не создаёт никаких связей.

### Ошибка авторизации

Если пользователь не авторизован,
возвращается 401 Unauthorized.

```json
{
  "message": "Необходима авторизация"
}
```

## Принятые проектные решения

Список относится к текущему авторизованному пользователю.
Каждый элемент ответа содержит номер друга в поле userId.
Такой формат ответа выбран для этого контракта.
