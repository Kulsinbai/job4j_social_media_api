# Состояния и переходы заявки в друзья

Колонка **Ответ HTTP** — результат вызова команды из **исходного состояния** строки
(первый успешный переход или ответ при отсутствии перехода).

Колонка **Результат повторного вызова** — ответ, если ту же команду выполнить снова,
когда заявка **уже находится в новом состоянии** этой строки.

| Команда | Исходное состояние | Новое состояние | Изменение подписки | Изменение дружбы | Ответ HTTP | Результат повторного вызова |
| --- | --- | --- | --- | --- | --- | --- |
| offerFriendship | Заявка отсутствует | PENDING | Инициатор подписывается на получателя | Без изменений | 201 Created, JSON заявки | 204 No Content |
| acceptFriendship | Заявка ожидает ответа (PENDING) | ACCEPTED | Получатель подписывается на инициатора. Подписка инициатора сохраняется | Создаётся взаимная дружба | 200 OK, JSON заявки со статусом ACCEPTED | 204 No Content |
| rejectFriendship | Заявка ожидает ответа (PENDING) | REJECTED | Подписка инициатора сохраняется, новых подписок нет | Дружба не создаётся | 200 OK, JSON заявки со статусом REJECTED | 204 No Content |
| offerFriendship | Заявка ожидает ответа (PENDING) | PENDING | Подписка инициатора сохраняется, новых подписок нет | Дружба не создаётся | 204 No Content | 204 No Content |
| offerFriendship | Заявка принята (ACCEPTED) | ACCEPTED | Обе подписки сохраняются, дубликаты не создаются | Дружба сохраняется, дубликаты не создаются | 204 No Content | 204 No Content |
| offerFriendship | Заявка отклонена (REJECTED) | REJECTED | Подписка инициатора сохраняется, новых подписок нет | Дружба не создаётся | 409 Conflict | 409 Conflict |
| acceptFriendship | Заявка принята (ACCEPTED) | ACCEPTED | Обе подписки сохраняются, дубликаты не создаются | Дружба сохраняется, дубликаты не создаются | 204 No Content | 204 No Content |
| rejectFriendship | Заявка принята (ACCEPTED) | ACCEPTED | Обе подписки сохраняются, дубликаты не создаются | Дружба сохраняется, дубликаты не создаются | 409 Conflict | 409 Conflict |
| acceptFriendship | Заявка отклонена (REJECTED) | REJECTED | Подписка инициатора сохраняется, новых подписок нет | Дружба не создаётся | 409 Conflict | 409 Conflict |
| rejectFriendship | Заявка отклонена (REJECTED) | REJECTED | Подписка инициатора сохраняется, новых подписок нет | Дружба не создаётся | 204 No Content | 204 No Content |

## Уточнение обработки повторных команд

Для offerFriendship, acceptFriendship и rejectFriendship:

- Первое успешное **создание** заявки возвращает **201 Created** с JSON заявки.
- Повторное **создание** при статусе **PENDING** или **ACCEPTED** — **204 No Content**.
- **Создание** при статусе **REJECTED** — **409 Conflict**.
- Первое успешное **принятие** или **отклонение** из **PENDING** — **200 OK** с JSON заявки и соответствующим статусом.
- Повтор команды, результат которой уже достигнут (**accept** при **ACCEPTED**, **reject** при **REJECTED**, повторный **create** при **PENDING** или **ACCEPTED**), — **204 No Content** без тела.
- Попытка изменить окончательное решение (**accept** при **REJECTED**, **reject** при **ACCEPTED**, **create** при **REJECTED**) — **409 Conflict**.
- Повторные команды не изменяют состояние заявки и не создают дублирующие связи.
