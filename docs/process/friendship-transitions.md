# Состояния и переходы заявки в друзья

| Команда | Исходное состояние | Новое состояние | Изменение подписки | Изменение дружбы | Результат повторного вызова |
| --- | --- | --- | --- | --- | --- |
| offerFriendship | Заявка отсутствует | PENDING | Инициатор подписывается на получателя | Без изменений | 204 No Content, состояние остаётся PENDING |
| acceptFriendship | Заявка ожидает ответа (PENDING) | ACCEPTED | Получатель подписывается на инициатора. Подписка инициатора сохраняется | Создаётся взаимная дружба | 204 No Content, состояние остаётся ACCEPTED |
| rejectFriendship | Заявка ожидает ответа (PENDING) | REJECTED | Подписка инициатора сохраняется, новых подписок нет | Дружба не создаётся | 204 No Content, состояние остаётся REJECTED |
| offerFriendship | Заявка ожидает ответа (PENDING) | PENDING | Подписка инициатора сохраняется, новых подписок нет | Дружба не создаётся | 204 No Content, состояние остаётся PENDING |
| offerFriendship | Заявка принята (ACCEPTED) | ACCEPTED | Обе подписки сохраняются, дубликаты не создаются | Дружба сохраняется, дубликаты не создаются | 204 No Content, состояние остаётся ACCEPTED |
| offerFriendship | Заявка отклонена (REJECTED) | REJECTED | Подписка инициатора сохраняется, новых подписок нет | Дружба не создаётся | 409 Conflict, состояние остаётся REJECTED |
| acceptFriendship | Заявка принята (ACCEPTED) | ACCEPTED | Обе подписки сохраняются, дубликаты не создаются | Дружба сохраняется, дубликаты не создаются | 204 No Content, состояние остаётся ACCEPTED |
| rejectFriendship | Заявка принята (ACCEPTED) | ACCEPTED | Обе подписки сохраняются, дубликаты не создаются | Дружба сохраняется, дубликаты не создаются | 409 Conflict, состояние остаётся ACCEPTED |
| acceptFriendship | Заявка отклонена (REJECTED) | REJECTED | Подписка инициатора сохраняется, новых подписок нет | Дружба не создаётся | 409 Conflict, состояние остаётся REJECTED |
| rejectFriendship | Заявка отклонена (REJECTED) | REJECTED | Подписка инициатора сохраняется, новых подписок нет | Дружба не создаётся | 204 No Content, состояние остаётся REJECTED |

## Уточнение обработки повторных команд

Для acceptFriendship и rejectFriendship в этой таблице принято следующее правило:

- Повтор команды, результат которой уже достигнут, возвращает 204 No Content.
- Попытка изменить окончательное решение возвращает 409 Conflict.
- Повторные команды не изменяют состояние заявки и не создают дублирующие связи.
