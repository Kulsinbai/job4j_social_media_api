# job4j_social_media_api

## Назначение проекта

Учебный проект: серверная часть социальной сети на Java и Spring Boot.

Приложение будет поддерживать предложения дружбы, подписки,
дружбу и уведомления. Позже появятся публикации, лента и переписка.

## Центральный процесс дружбы

1. Первый пользователь отправляет второму предложение дружбы.
2. Первый пользователь становится подписчиком второго.
3. Второй пользователь принимает предложение.
4. Между пользователями создаётся дружба.
5. Оба пользователя становятся подписчиками друг друга.
6. Система отправляет уведомления.

## Требования

Для запуска проекта должны быть установлены:

- Java 21 или новее;
- Docker Desktop.

PostgreSQL отдельно устанавливать не требуется. База запускается в Docker.

## Подготовка локального окружения

После клонирования проекта нужно создать локальный файл `.env`
из примера `.env.example`.

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Linux и macOS:

```bash
cp .env.example .env
```

Параметры PostgreSQL по умолчанию:

- база данных: `social_media`;
- адрес: `localhost`;
- порт: `5432`;
- пользователь: `postgres`;
- пароль: `password`.

Файл `.env` содержит локальные настройки и не отправляется в Git.

## Запуск PostgreSQL

Запустите PostgreSQL в Docker:

```bash
docker compose up -d
```

Проверьте состояние контейнера:

```bash
docker compose ps
```

PostgreSQL готов к работе, когда в столбце состояния появился статус `healthy`.

Посмотреть журнал PostgreSQL:

```bash
docker compose logs postgres
```

## Запуск приложения

Windows PowerShell:

```powershell
.\mvnw.cmd spring-boot:run
```

Linux и macOS:

```bash
./mvnw spring-boot:run
```

При первом запуске Liquibase автоматически создаст таблицы базы данных.

## Проверка API

После запуска приложения откройте в браузере:

http://localhost:8080/api/ping

Обработчик принимает GET-запрос и возвращает HTTP-статус 200
с JSON-ответом:

```json
{
  "status": "ok",
  "service": "social-media-api"
}
```

## Сборка и тесты

Перед запуском тестов PostgreSQL в Docker должен иметь статус `healthy`.

Windows PowerShell:

```powershell
.\mvnw.cmd clean verify
```

Linux и macOS:

```bash
./mvnw clean verify
```

Тесты проверяют запуск Spring Context и ответ `GET /api/ping`.
Во время сборки также выполняются проверки CheckStyle и создаётся отчёт JaCoCo.

## Остановка окружения

Остановить контейнер без удаления данных:

```bash
docker compose down
```

При следующем запуске сохранённые таблицы и данные останутся на месте.

Полностью удалить контейнер и локальные данные PostgreSQL:

```bash
docker compose down -v
```

Команда с флагом `-v` удаляет Docker volume вместе с данными.
Используйте её только для очистки локального учебного окружения.
